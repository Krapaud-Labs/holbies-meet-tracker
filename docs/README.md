# Documentation du projet

Cette documentation décrit le périmètre, les flux, l'architecture et les contrôles du MVP Holbies Meet Tracker. Les documents restent alignés avec le code de l'extension Chrome Manifest V3.

## Parcours principal

Le parcours est : connexion Google explicite, lecture des événements Agenda, sélection d'un événement Meet, lecture des participants et de leurs sessions, calcul d'un statut, puis export consenti vers une nouvelle feuille Sheets.
